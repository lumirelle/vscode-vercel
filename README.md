# VSCode Vercel

> [!Note]
> This is a personal usage fork for [gantoreno/vscode-vercel](https://github.com/gantoreno/vscode-vercel), built from the [vercel.nvim](https://github.com/lumirelle/vercel.nvim) palette
> ([`SCHEMA.md`](https://github.com/lumirelle/vercel.nvim/blob/main/SCHEMA.md) / [`lua/vercel/colors.lua`](https://github.com/lumirelle/vercel.nvim/blob/main/lua/vercel/colors.lua)).
>
> Since this repository is a self-hosted fork, there are no plans to publish it to the
> [Visual Studio Marketplace](https://marketplace.visualstudio.com/) or
> [Open VSX](https://open-vsx.org/). To use this extension, download the `.vsix` package
> from the [GitHub release page](https://github.com/lumirelle/vscode-vercel/releases) and
> install it locally:
>
> ```sh
> code --install-extension vscode-vercel-theme-<version>.vsix
> ```
>
> Alternatively, in VS Code go to the **Extensions** view, click the `...` menu at the
> top and choose **Install from VSIX...**.

A carefully crafted set of colorschemes based on the [Vercel Geist design system](https://vercel.com/geist/introduction).
